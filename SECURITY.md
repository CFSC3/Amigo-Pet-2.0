# 🛡️ Política de Segurança — Amigo Pet

A segurança dos dados dos tutores, ONGs e estabelecimentos parceiros é uma prioridade no ecossistema **Amigo Pet**.

## 📌 Versões Suportadas

Atualmente, apenas a versão mais recente da arquitetura refatorada recebe atualizações ativas de segurança e correções de vulnerabilidades:

| Versão | Suportada |
| :--- | :---: |
| **v2.5.x** | ✅ Sim |
| **v2.0.x - v2.4.x** | ⚠️ Apenas correções críticas |
| **< v2.0 (Legado)** | ❌ Não |

## 🚨 Como Reportar uma Vulnerabilidade

Se você encontrou alguma falha de segurança, brecha de autenticação (ex: bypass do modo Visitante), exposição de rotas no Firebase ou comportamento inesperado:

1. **NÃO abra uma Issue pública** no GitHub descrevendo a vulnerabilidade, para proteger a comunidade até que a correção seja lançada.
2. Envie um relatório detalhado diretamente para o e-mail: **Carlosfelipesouzacarvalho@gmail.com** com o assunto `[SECURITY] Amigo Pet - Relato de Vulnerabilidade`.
3. Inclua no e-mail:
    * Passo a passo para reproduzir o problema;
    * Telas ou módulos afetados (Feed, Chat, Mapa, Doações ou Perfil);
    * Logs ou capturas de tela/vídeo, se possível.

## ⏱️ Prazo de Resposta
* **Confirmação de recebimento:** em até 48 horas.
* **Análise técnica e lançamento de patch (Hotfix):** entre 3 a 7 dias úteis, dependendo da criticidade.
